# CiboCocinar — AI-Powered Voice Cooking Assistant

[![Live](https://img.shields.io/badge/live-cibo.esamz.info-brightgreen?style=for-the-badge)](https://cibo.esamz.info)
[![Also on Vercel](https://img.shields.io/badge/vercel-chef--mind--rho-brightgreen?style=flat-square)](https://chef-mind-rho.vercel.app)

> **Recipes generated by AI, cooked hands-free. CiboCocinar turns "what do I cook tonight?" into a spoken, step-by-step kitchen companion.**

This repository is the **landing page** for CiboCocinar — one of the eSAMz
Worlds from [esamz.me](https://esamz.me). The manifest describes the product as
*"an AI-powered voice cooking assistant that allows users to generate and follow
recipes hands-free using Sarvam AI and eSAMz technology."*

## What the landing page covers

- **AI recipe generation** — describe what you have; get a cookable recipe
- **Hands-free cooking mode** — spoken steps so your hands stay on the knife, not the screen
- **Voice interaction** — a voice button drives the experience (the site's voice button)
- **Recipe browsing** — curated recipe cards
- **How-it-works & FAQ** — the product story told on one page
- **PWA-ready** — `site.webmanifest`, theme color, Apple/Android touch icons installed

## What's in this repo

| Path | What it is |
|---|---|
| `index.html` | The complete landing page — 859 lines, one hand-crafted file |
| `site.webmanifest` | PWA manifest with product description and category |
| `favicon.*`, `apple-touch-icon.png`, `android-chrome-*.png` | Full icon set |

Single-file, no-build-tool approach — trivially hostable anywhere. The site is
live at **[cibo.esamz.info](https://cibo.esamz.info)** and on Vercel at
[chef-mind-rho.vercel.app](https://chef-mind-rho.vercel.app).

## Run locally

```bash
python3 -m http.server 8080
# → http://localhost:8080
```

## Tech notes

- Tailwind via CDN + Font Awesome + Google Fonts (Poppins / Playfair Display)
- PWA manifest and complete icon set committed to the repo
- Vanilla JS interactions (mobile menu, popups, voice button)
